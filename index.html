How to use

1. Pick a map tab (maps load automatically; a green ● means an image is loaded).
2. Drag a player from the roster onto the map. Drag the marker to move; grab the white handle to rotate his facing.
3. Sliders set view width & range; tag Up/Down for verticality.
4. Toggle Draw (toolbar) to sketch arrows/notes in any color; Erase, Undo, Clear.
5. Save stores all maps, players & sketches; Print exports the current map.
